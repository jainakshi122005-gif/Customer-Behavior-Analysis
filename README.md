# Customer Behavior Analysis

## Project Overview

This project focuses on analyzing customer shopping behavior to understand purchasing patterns, customer preferences, and spending trends.

The objective is to generate meaningful business insights using Python, SQL, PostgreSQL, and Power BI.

## Tools & Technologies

- Python
- Jupyter Notebook
- SQL
- PostgreSQL
- Power BI
- Pandas
- Matplotlib
- Seaborn

## Dataset Overview

- Dataset: Customer Shopping Behavior
- Total Records: 3,900
- Total Columns: 18

The dataset contains customer-related information, shopping preferences, purchase amounts, discounts, shipping methods, and review ratings.

## Project Workflow

1. Data Analysis Using Python

- Data loading and inspection
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Identifying customer purchasing patterns

2. SQL Analysis Using PostgreSQL

Business questions explored through SQL queries:

- Revenue generated by male and female customers
- Spending behavior of discount users
- Top-rated products
- Shipping method analysis
- Subscriber vs. non-subscriber spending

### SQL Business Questions

1. What is the total revenue generated by male vs. female customers?
2. Which customers used a discount but still spent more than the average purchase amount?
3. Which are the top 5 products with the highest average review rating?
4. Compare average purchase amounts between Standard and Express Shipping.
5. Do subscribed customers spend more?
6. Which products have the highest discount rate?
7. Segment customers into New, Returning, and Loyal.
8. What are the top 3 most purchased products within each category?
9. Are repeat buyers likely to subscribe?
10. What is the revenue contribution of each age group?

3\. Power BI Dashboard

An interactive dashboard was created to visualize customer shopping behavior and business insights.

## Key Project Deliverables

- Python Jupyter Notebook
- PostgreSQL SQL Queries
- Power BI Dashboard
- Dashboard Screenshot
- Dataset

## Project Objective

To transform raw customer shopping data into meaningful insights that can help businesses understand customer behavior and support better decision-making.

## Conclusion

This project demonstrates practical skills in data cleaning, exploratory data analysis, SQL querying, data visualization, and business intelligence using real-world analytical tools.
